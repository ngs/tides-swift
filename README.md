# Tides

A native iOS, iPadOS, macOS, visionOS, and watchOS application for offline tide prediction. Pick a point on the map, download its harmonic constituent parameters once from [tides-api](https://api.tides.ngs.io/), and all tide predictions are computed locally on device — no network connection required afterwards.

## Features

### Core Functionality
- **Offline Tide Prediction**: Harmonic tide computation (`h(t) = msl + Σ f·A·cos(ωΔt + V + u − φ)`) runs entirely on device, ported from the Go implementation in tides-api and validated against golden fixtures generated by it
- **One-Time Parameter Download**: `GET /v1/tides/parameters` returns the harmonic constituents for a coordinate; they are stored with SwiftData and reused forever
- **Interactive Map Picker**: Tap anywhere on the map to select a location; MapKit reverse geocoding suggests a name
- **Two-Day Tide Chart**: Swift Charts curve with high/low water markers, a "now" indicator and day navigation
- **High/Low Water Times**: Extrema located on a 1-minute grid and refined by parabolic interpolation
- **Saved Locations**: Multiple locations persisted with SwiftData, shown in a sidebar (NavigationSplitView)
- **Apple Watch App**: Companion watchOS app showing the current tide and next high/low water

## Architecture

Logic lives in a local Swift package (`Package.swift`) with three libraries; the Tuist-managed app targets depend on them.

- **TidesCore** (`Sources/Core/`) — depends on Foundation only, builds for all platforms including watchOS
  - `HarmonicParameters.swift`: Codable model of the `/v1/tides/parameters` response
  - `NodalCorrection.swift`: Astronomical nodal corrections f/u (Schureman 1958)
  - `TidePredictor.swift`: Height series, high/low water detection and refinement
  - `API/TidesAPIClient.swift`: URLSession client for the parameters endpoint

- **TidesPlatform** (`Sources/Platform/`)
  - `Storage/SavedLocation.swift`: SwiftData model persisting the downloaded parameters as JSON
  - `Location/ReverseGeocoder.swift`: CLGeocoder-based name suggestions

- **TidesUI** (`Sources/UI/`)
  - `Views/`: `ContentView` (split view), `LocationListView`, `AddLocationView` (map picker), `LocationDetailView` (chart)
  - `ViewModels/`: `AddLocationViewModel`, `LocationDetailViewModel`

The engine is a port of the Go implementation in tides-api (`internal/domain/tide.go`, `nodal.go`). Golden fixtures in `Tests/TidesCoreTests/Fixtures/` are generated from the Go code; the Swift port must match them within the tolerances recorded in each fixture.

## API Integration

Base URL: `https://api.tides.ngs.io/` (configurable via the `API_HOST` Info.plist key)

- `GET /v1/tides/parameters?lat={lat}&lon={lon}` — harmonic constituent parameters (the only endpoint the app needs)

## Privacy

Tides respects your privacy:
- Minimal data collection
- No analytics tracking
- A single API request per saved location; predictions never leave the device
- Location data stays on device (used only for reverse geocoding)
